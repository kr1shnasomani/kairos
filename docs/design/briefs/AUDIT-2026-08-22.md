## The defect that actually dominates

**`text-accent` on identifiers — 93 elements across four pages.**

This is review items 22, 32 and 34, and it is exactly what `DESIGN.md` §2.3 exists to fix: `--accent`
is the brand orange sitting ~10° from the alarm red, so every ID, framework name and document
reference reads as an error. `/projects` alone has 41.

Phase B fixed the four call sites I could find by grep. The DOM count shows the real scale — most are
inside components I had not opened.

**This one change, applied correctly across the five pages, is the bulk of Phase C's value.**

## Lesson for the briefs

I wrote three briefs from the senior review without opening the files. Two were substantially wrong
and one had the wrong file list entirely — caught only because the C1 agent refused to work outside
its scope rather than guessing.

**Every brief claim is now traced to either the DOM or a line number.** Where the review and the code
disagree, the code wins and the brief says so.
